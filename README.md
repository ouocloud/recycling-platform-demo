# 再生资源产业互联网平台演示系统

## 启动

这是纯 HTML / CSS / JavaScript 静态项目，无需安装依赖、构建工具或后端。解压后进入 `recycling-platform-demo`，可直接打开 `index.html`；如需稳定使用浏览器本地存储，建议在目录中运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。桌面后台建议使用 1440px 及以上宽度；手机 H5 可用手机浏览器访问，或将浏览器视口设为 375–430px。

## 角色专属工作台

身份切换会同时改变首页指标、快捷操作、菜单、业务模块和记录范围，不只是更换标题。电脑后台与手机 H5 使用同一套角色范围：

- 平台总管理员：平台全域指标、企业与用户管理、全平台订单、物流和风控控制。
- 企业管理员：只查看当前企业关联订单、员工、库存、资金和发票；员工新增固定归属本企业，企业设置仅显示本企业档案。
- 司机：仅显示分配给本人车辆的运输任务；开始运输、装货、到达、卸货等状态更新关联到本人任务。
- 回收员：登记本人回收记录、查看本人批次及追溯，不显示其他回收人员数据。
- 仓库员：查看授权仓库批次、库存和称重；入库与盘点操作只改变授权批次。
- 工厂采购员：只处理本厂采购订单、到货验收及关联发票。
- 财务人员：查看本企业结算账本、待结算和发票；结算按钮按待结算记录推进模拟状态。

上述限制用于演示岗位差异和前端记录筛选，不是服务端安全边界；正式上线仍需真实登录认证与后端租户权限校验。

## 可操作演示

- 创建订单并自动生成批次档案；订单可查询、查看详情和推进状态。
- 平台管理员可创建运输任务，在本地 SVG 示意地图上模拟车辆移动；司机确认运输/到达/卸货会更新共享的本地状态。
- 模拟完整称重流程，自动计算“净重 = 毛重 - 皮重”，生成磅单并更新订单、批次与追溯事件。
- 查询批次时间轴并查看扫码演示；二维码图案用于界面交互演示，不是实际可扫描编码。
- 模拟结算、发票申请与发票状态推进；风险事件可生成并标记人工核查。
- 企业、用户、订单、物流、库存、称重、追溯、财务、发票、风控和设置模块依角色授权浏览；电脑后台与 H5 共用本地模拟记录。
- 新增岗位待办与审批中心：企业资质、交易确认、到货验收、仓库收货、财务结算和发票资料按角色范围集中处理，操作写入本地日志。
- 订单台账增加合同草案编号、交付窗口、付款账期、验收标准、业务负责人及变更时间轴；合同摘要仅供演示，不构成正式法律文件，也不含电子签章。
- 企业管理员可维护本企业联系人、演示税号、结算周期、授信额度、默认仓库和质量阈值；这些是本地演示参数，不会影响其他企业。
- 交易阶段按报价 / 确认、派车、运输、验收、结算逐步推进；订单价格固定，司机运输状态、验收结果、批次追溯和结算台账联动。

## 数据与限制

- 初始数据至少包含 10 家企业、20 名用户、15 辆车辆、30 笔订单、20 个批次、30 条称重记录、20 条运输记录、20 条发票和结算记录、15 条风控事件。
- 改动使用 `localStorage` 保存。同一浏览器、同一网页来源的标签页可通过浏览器存储事件看到彼此更新；这不是云端或跨设备同步。浏览器清理站点数据会恢复种子数据。
- 行情、GPS/车辆位置、路线、速度、称重、支付凭证、结算及电子票样均为模拟数据，不代表实时市场、真实定位、实体地磅、真实资金转账或税务机关签发/接入。
- 目前没有后端账号认证、服务端租户隔离或真实设备/地图/支付/税务 API；系统页注明了建议的 API 接入位置。
- 该项目是交互演示，不可用于生产业务或真实财务、税务决策。
